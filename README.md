# SiteLimit

**Управляйте временем на сайтах в Яндекс Браузере на Android.**

SiteLimit помогает меньше отвлекаться на сайты, не отказываясь от браузера целиком. Задайте дневной лимит для нужного сайта — приложение будет отслеживать время и сообщит, когда лимит исчерпан.

## Возможности

- Индивидуальные дневные лимиты для отдельных сайтов.
- Учёт времени на сайте и его поддоменах.
- Автоматический ежедневный сброс лимитов.
- Отображение использованного времени.
- Поддержка Яндекс Браузера и приложения «Яндекс — с Алисой».

## Конфиденциальность

Данные о лимитах и использовании хранятся на устройстве. Для основной функции приложение не требует подключения к интернету. Для учёта времени используется служба специальных возможностей Android.

## Как начать

1. Установите приложение из доверенного источника.
2. Следуйте инструкциям приложения для включения службы специальных возможностей.
3. Добавьте сайт и задайте дневной лимит в минутах.
